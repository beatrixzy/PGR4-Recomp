# Title Update & DLC Setup guide
To setup DLC and Title Updates, you need to do a few things:

1. **Extract the ISO - Easy, as you can drag and drop an ISO onto the launcher, and it'll extract it for you!**

2. **Create a `Content` folder** inside the game folder (where the ISO is extracted to!):

   ```
   C:\Games\PGR4-Files\
   ├── default.xex
   ├── Game\
   ├── UI\
   ├── ...
   └── Content\        <- create this
   ```

3. **Copy the title update and any DLC files into `Content`**:

   ```
   C:\Games\PGR4-Files\Content\
   ├── TU_16L61VP_0000004000000.00000000000G1
   └── 638152C719C45657B6640991BA6375D88A9D437D4D   (optional DLC)
   ```

4. **Point the launcher to the extracted game files, and if need be, add it to the content tab in the Launcher**
