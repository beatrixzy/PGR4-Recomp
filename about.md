# About this project
PGR4-Decomp (or rather, recomp) is a project that intends to port Project Gotham Racing 4 to PC. All of this is possible, thanks to the [ReXGlue SDK](https://github.com/rexglue/rexglue-sdk), allowing me to convert meaningless PowerPC code to C++ so our modern day computers can understand.
Now, you may be wondering, "What inspired you to make this recompilation of Project Gotham Racing 4?", and to put it simply, I love the game, seriously. It was one of the first ever racing games I ever played, so I wanted to keep it as alive as possible!
